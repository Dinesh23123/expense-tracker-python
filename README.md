# 💰 Expense Tracker (Python)

A simple **console-based Expense Tracker** built using **Python, Functions, and File Handling**.
This program allows users to store and manage their daily expenses through a menu-driven interface.

The application stores expense data permanently in a text file, allowing users to add, view, search, calculate totals, and delete expenses.

---

## 📌 Features

* ➕ Add a new expense
* 📋 View all stored expenses
* 🔍 Search expenses by category
* 💰 Calculate total expenses
* ❌ Delete an expense
* 💾 Persistent data storage using a text file

---

## 🛠 Technologies Used

* Python
* File Handling
* Functions
* Loops and Conditional Statements

---

## 📂 Project Structure

```
expense-tracker
│
├── expense_tracker.py
└── expense.txt
```

* **expense_tracker.py** → Main Python program
* **expense.txt** → Stores all expense data

---

## ⚙️ How the Program Works

The program runs in a **menu-driven loop** where the user selects options to manage expenses.

### Menu Options

```
1. Add Expense
2. View Expenses
3. Search by Category
4. Show Total Expense
5. Delete Expense
6. Exit
```

---

## 📝 Expense Data Format

Expenses are stored in the file in the following format:

```
Date,Category,Amount
```

Example:

```
2026-03-06,Food,200
2026-03-06,Travel,150
2026-03-07,Shopping,500
```

## 🚀 How to Run the Project

1. Install Python (if not already installed)

2. Clone the repository

```
git clone https://github.com/your-username/expense-tracker.git
```

3. Navigate to the project folder

```
cd expense-tracker
```

4. Run the program

```
python expense_tracker.py
```
